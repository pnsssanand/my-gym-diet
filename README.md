# MY GYM DIET 🏋️‍♂️🥗

> **Premium Fitness & Nutrition Management Platform** tailored for high-performance athletes requiring strict lactose-free / dairy-free nutritional balance with a constant **120g daily protein** target.

---

## ✨ Features

- **Constant 120g Daily Protein Schedule**:
  - Full 30-day personalized meal plan hitting exactly **120g protein** and ~1,950 kcal every single day.
  - Automatic time-based meal strikeout for out-of-time meals.
  - Active window highlighting ("Eat Now") so athletes always know their immediate nutrition goal.
- **100% Strictly Dairy-Free Nutrition**:
  - Zero milk, curd, yogurt, paneer, cheese, butter, whey, casein, cream, or ghee.
  - Sourced from egg whites, lean chicken breast, tilapia fish, soya granules (52% protein density), firm tofu, yellow moong dal, and roasted chana sattu.
- **Recipe Library with Verified Food Photography**:
  - 19 authentic Indian high-protein recipes with exact digital gram measurements.
  - Step-by-step cooking directions, equipment list, macros, and dairy-free substitutions.
- **Kitchen Essentials & Grocery Logistics**:
  - Consolidated 30-day grocery list with quantities in kilograms/grams and prices in **British Pounds (£)**.
  - "Bring From India" checklist for authentic fitness staples (sattu, kala namak, spices).
  - Personal equipment shopping checklist with priority filtering.
- **Interactive Water Tracker**:
  - Calibrated for 61 kg body weight (2,600 ml daily target) to ensure kidney filtration of protein metabolites.
  - 3D animated hydration glass and 7-day intake trend chart.
- **Workout Tasks & Nutrition Notes**:
  - Task manager with status filtering and due dates.
  - Pin-to-top nutrition notes and progressive overload log.
- **Dual Backend Persistence**:
  - Firebase Authentication & Cloud Firestore synchronization.
  - Resilient local storage fallback for instantaneous offline operation.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/pnsssanand/my-gym-diet.git

# Navigate to project folder
cd my-gym-diet

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Building for Production

```bash
npm run build
```
